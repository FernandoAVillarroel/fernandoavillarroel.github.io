Experiencia

Desarrollador Full Stack - Pasantía

Instituto Provincial de Vivienda y Urbanismo (IPVU)

Santiago del Estero, Argentina

Jun 2024 - Nov 2024

Durante mi pasantía en el IPVU, lideré el desarrollo completo del sistema FONAVI (Fondo Nacional de Vivienda), una aplicación web crítica para la gestión de empleados y liquidación automatizada de sueldos. Este proyecto optimizó procesos manuales que afectaban directamente a los trabajadores del instituto.

Responsabilidades principales:
  • Diseño e implementación de arquitectura full stack desde cero: Django (backend), MySQL (base de datos) y frontend con JavaScript, CSS3 y Bootstrap 5
  • Desarrollo de interfaces de usuario responsivas e intuitivas optimizadas para diferentes dispositivos
  • Implementación de funcionalidades dinámicas e interactivas con JavaScript vanilla para mejorar la experiencia del usuario
  • Gestión de base de datos relacional con múltiples tablas para empleados, conceptos salariales y liquidaciones
  • Aplicación de medidas de seguridad para proteger datos sensibles de nómina
Problemas resueltos:
  • Proceso manual de cálculo: Automaticé completamente el cálculo de liquidaciones que antes tomaba días y generaba errores frecuentes, reduciéndolo a minutos con precisión del 100%
  • Datos dispersos: Centralicé información de empleados que estaba fragmentada en múltiples hojas de Excel, creando una única fuente de verdad accesible desde cualquier lugar
  • Falta de trazabilidad: Implementé un historial completo de liquidaciones que permite auditar y consultar cualquier pago histórico
  • Exportación de reportes: Desarrollé sistema de generación automática de comprobantes de pago en PDF y reportes en Excel, eliminando la creación manual de documentos
  • Curva de aprendizaje: Diseñé una interfaz intuitiva con validaciones en tiempo real que permite usar el sistema sin capacitación técnica previa
  • Seguridad de datos: Implementé autenticación robusta, control de accesos por roles y validación exhaustiva de datos para proteger información financiera confidencial
Tecnologías utilizadas:
Python Django JavaScript MySQL Bootstrap 5 HTML5 CSS3 Git
